## 6. Trend Signals

### Signal 1: Context Engineering Is the New Performance Engineering
Auto-compaction failures, runaway token consumption, and context budget shocks are the dominant crisis across **Claude Code, Codex, OpenCode, and Qwen Code** simultaneously. This is not a tool-specific bug — it's an industry-wide systems challenge as context windows grow and multi-turn agent workflows become longer. **Implication:** Developers should budget for context management as a first-class operational concern, not an afterthought.

### Signal 2: MCP Is Entering the "Production Reliability" Phase
Six months ago, MCP support was a feature differentiator. Today, **OpenCode has a Desktop-breaking MCP regression, Copilot silently disabled third-party MCP for orgs, and Qwen is hardening MCP self-modification paths.** The community is demanding project-scoped configs, tool-level permission allow-lists, and atomic config writes. **Implication:** MCP governance (scoping, approval gating, atomic config) will be a baseline requirement by Q3 2026.

### Signal 3: Windows Is the Persistent Underclass
Five of seven tools have active, high-engagement Windows bug clusters. The issues range from fundamental (ARM64 support, sandbox bootstrap) to UX (non-ASCII shell handling, garbled rendering). **No tool has achieved true Windows parity.** **Implication:** Teams with significant Windows developer populations should weight cross-platform maturity heavily in tool selection — or expect to maintain workaround documentation.

### Signal 4: Local and Multi-Provider Model Support Is a Table Stake
Requests for Ollama, vLLM, llama.cpp, OpenRouter, MiniMax, and BYOM endpoints appear across **Qwen Code, Pi, OpenCode, and Codex.** The `developer`-role incompatibility (affecting Pi with OpenRouter/Qwen/MiniMax) reveals that provider abstraction layers are still brittle. **Implication:** Tool-agnostic model routing is becoming a baseline expectation. Tools that lock users into a single provider's model catalog will face migration pressure.

### Signal 5: Token Economics Are Now a Product Concern
DeepSeek V4 Pro's 75% price drop created an immediate demand for recalculated usage limits on **OpenCode Go.** Copilot shows stale `$0.00 (sub)` pricing for now per-token-billed models on **Pi.** Developers are actively calculating cost-per-token across providers. **Implication:** Tools that provide transparent cost tracking, dynamic limit adjustment, and provider price awareness will have a competitive advantage.

### Signal 6: Agent Correctness and Observability Are Emerging Differentiators
**Gemini CLI** is investing in component-level behavioral evals (76 tests). **Qwen Code** is building subagent telemetry span isolation. **OpenCode** is adding memory diagnostics dumps. The community is moving from "does the agent produce output?" to "can I trust the agent's output and diagnose failures?" **Implication:** Agent observability (eval frameworks, telemetry, deterministic redaction) will become a key evaluation criterion for enterprise adoption.

### Signal 7: TUI Quality Is a Silent Retention Factor
CJK rendering, Kitty/WezTerm image support, OSC 8 clickable links, vim mode, auto-scroll reliability — **every tool** has active TUI work. These are not glamorous features, but they determine whether developers use the tool for hours or minutes. **Implication:** Terminal UX polish is a retention lever. Tools with fragile TUIs will see usage drop-off regardless of agent capability.
