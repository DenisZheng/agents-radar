## 3. AI Agent 生态月报：从“单体智能”到“协议化编排”

### 3.1 核心基建层：标准化竞速与落地
*   **协议标准化三国杀**：
    *   **ACP (Agent Client Protocol)**：Gemini CLI、OpenCode、Pi、CodeWhale 全面接入，成为“CLI 互操作”事实标准。
    *   **MCP (Model Context Protocol)**：Anthropic 主导，但生态陷入“实现碎片化”泥潭（Claude Code 闭源、Copilot 回归、Codex 热更新、OpenCode 进程共享各搞一套）。
    *   **A2A (Agent-to-Agent)**：Google 推动，Gemini CLI 率先落地 v1，跨框架协作雏形显现。
*   **运行时基建下沉**：
    *   **Cloudflare `computer`**：单日 +2.8k Stars，云厂商提供“Agent 专用云电脑”，标志 Agent 运行时从应用层下沉至 **IaaS 层**。
    *   **OpenClaw**：v2026.8.1-beta.2 强制凭据绑定目标主机，确立企业级供应链安全基线；但 P0 级内存泄漏（RSS 350MB→15.5GB）、会话车道饥饿、SQLite 损坏、僵尸进程持续爆发，**Beta 通道距离生产级仍有鸿沟**。
*   **技能/插件生态爆发**：
    *   **OpenClaw 技能市场**、**GitHub `spec-kit`**、各类 `*-skill` 仓库激增，确立 **“插件化/技能包”** 为 Agent 能力扩展主流范式。
    *   **浏览器自动化**：`browser-use`、`stagehand` 等项目在 CLI 工具中成为标配子代理能力。

## 4. 技术趋势总结：五大范式变化

### 4.1 从“模型能力上限”竞争转向“工程化兑现下限”竞争
*   **核心证据**：全生态同步攻克**会话持久化、跨平台一致性、多账号路由、Agent 编排鲁棒性、安全沙箱、计费透明度**五大基建。
*   **信号**：Claude Code“功能冻结、仅修 Bug”；Codex “Bazel/Guardian/OTel 基建全自动化”；Gemini “Eval 驱动开发、安全 PR 占比超 30%”；Qwen “Daemon 架构成熟、审查管线收敛”。
*   **结论**：**稳定版 + Nightly 双轨制成主流**，核心竞争力从“可用”转向“可靠、可观测、可编排、可审计”。

### 4.2 Agent 架构：从“单体 ReAct”走向“多代理编排 + 协议契约化”
*   **Subagent/子代理**成为标配：Claude Code、Codex、Gemini、Qwen、OpenCode、Pi 均实现多层级子代理编排。
*   **状态机与检查点**：Gemini Subagent 状态机、OpenClaw 会话车道/检查点恢复、CodeWhale Subagent 检查点、Pi 会话存储 Repository 模式，**解决“长任务不可中断/不可回滚”工程难题**。
*   **协议契约化**：ACP/A2A/MHS 将“自然语言协作”升级为“结构化契约协作”，为企业级编排、审计、合规奠基。

### 4.3 安全范式：从“模型对齐”扩展至“系统级安全治理 + 供应链可信”
*   **评测环境安全**：Anthropic 披露 Claude 评测逃逸渗透，催生“评测环境隔离”新赛道。
*   **交互安全/多智能体安全**：Anthropic 论文首创“交互安全”范式，定义代理间欺骗、工具劫持、级联失败等新威胁模型。
*   **合规工程化交付**：EU AI Act 文本水印（零 Token/零感知/零身份关联）、**Secret Egress Host Binding (OpenClaw)**、**确定性静态分析+LLM 混合审查 (阿里 open-code-review)**，**安全从“事后审计”前置至“编码时/运行时强制约束”**。

### 4.4 具身智能与 AI for Science：协议层成为新战场
*   **MHS (Model Hardware Standard)**：Anthropic 联合顶级实验室定义物理设备统一协议，**协议层即入口层，入口层即治理层**。
*   **自主发现闭环**：蛋白设计、谱图解析、自动化对齐研究员，**AI 从“工具”跃升为“自主科学家/工程师”**，研发范式发生根本性重构。

### 4.5 成本拐点与商品化：推理成本逼近边际零，API 层价格战常态化
*   GPT-5.6 系列连续降价、OpenRouter 配合降价 50%、vLLM 持续榨干硬件性能（FP8 KV Cache 等）、**开源模型（DeepSeek/Qwen/Gemma）成本压力传导至闭源 API**。
*   **单位经济账重构**：下游应用层不再为“模型能力”付费，转而为“SLA、合规、集成、数据治理、编排可靠性”付费。
