Today's data reveals three dominant patterns:

**① Agent Middleware Explosion.** The most explosive growth is not in base models but in the layer *around* agents. Projects like [stablyai/orca](https://github.com/stablyai/orca) (+331 stars today, new) — an IDE for managing parallel agent fleets — and [revfactory/harness](https://github.com/revfactory/harness) (+277, new) — auto-generating agent teams from domain descriptions — represent a new category: **Agent AD (Agent Developer Experience)**. [interviewstreet/hiring-agent](https://github.com/interviewstreet/hiring-agent) (resume-scoring agent), [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) (stock analysis agent with multi-source data), and [santifer/career-ops](https://github.com/santifer/career-ops) (14-mode job search agent) all follow this pattern. The bar for what counts as an "AI app" is rising: it now requires agentic orchestration, not just a chat wrapper.
