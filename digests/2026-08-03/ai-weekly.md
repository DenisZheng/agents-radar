## 4. 开源趋势：基建层标准化与垂直场景产品化并进

### 四大技术方向
1. **Agent Harness（智能体工装）成核心战场**

   - 竞争焦点：技能编排、上下文压缩、多 IDE 兼容、安全沙箱、研究优先开发。

2. **RAG 演进为“记忆与知识图谱”三位一体**
   - `Graphify-Labs/graphify`（代码确定性 AST 图谱）、`mem0ai/mem0`（通用记忆层）、`topoteretes/cognee`（长期记忆平台）。
   - 向量检索不再是终点，**结构化知识+持久化记忆+上下文压缩**成新标配。

3. **语音/多模态交互本地化落地加速**
   - HF 官方 `speech-to-speech` (+628⭐) 开箱即用本地语音 Agent；`abus-aikorea/voice-pro` 集成 Edge-TTS/CosyVoice/F5-TTS/Whisper/Demucs 全能语音 WebUI。
   - `ChromeDevTools/chrome-devtools-mcp` 官方出品，将浏览器 DevTools 封装为 MCP Server，**“浏览器即 OS”**趋势显现。

4. **极简/原生技术栈反潮流**
   - `The-Pocket/PocketFlow` (100 行框架)、`0xPlaygrounds/rig` (Rust 原生 LLM 框架)、`AarambhDevHub/aarambh-studio` (纯 Rust LLM Studio)、`minimind` (2 小时训练 64M 模型)。
   - 社区对 Python 重依赖反思，**轻量化部署、边缘侧推理**需求强烈。

### 垂直场景产品化爆发
- **代码审查**：阿里 `open-code-review`（确定性管道+LLM Agent，行级精准，内置安全规则）。
- **金融基座**：`Kronos` 金融时序 Foundation Model 登榜，“小而精”垂直模型商业价值超通用大模型。
- **多模态技能包**：`bradautomates/claude-video` (视频理解技能)、`airi` (语音/游戏具身)。
- **技能包分发范式**：`reverse-skill` (安全逆向)、`last30days-skill` (深度调研)、`k-skill` (本地化开发) 以“Skill”形式接入 Claude Code/Cursor，**Agent 能力复用与分发雏形初现**。
