## 2. Releases

**v2.1.178** ([Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.178))

- **`Tool(param:value)` permission rule syntax**: Users can now match tool input parameters directly in permission rules. Use `Agent(model:opus)` to block Opus subagent spawning, or use `*` as a wildcard. This gives teams fine-grained control over which models and tool invocations are permitted without resorting to blanket denials.
- **Nested `.claude/skills` loading**: Skills defined in nested `.claude/skills` directories are now loaded when the assistant is working on files within those directories. On name clashes, the nested (more specific) skill takes priority — a natural scoping improvement for monorepos and large projects.

## 6. Developer Pain Points

**1. macOS ENOSPC cluster — the #1 reliability complaint.**
Issues [#63909](https://github.com/anthropics/claude-code/issues/63909), [#65166](https://github.com/anthropics/claude-code/issues/65166), [#65915](https://github.com/anthropics/claude-code/issues/65915), [#65067](https://github.com/anthropics/claude-code/issues/65067), and [#68383](https://github.com/anthropics/claude-code/issues/68383) — spanning Apple Silicon and Intel, Darwin 24.x and 25.x — all report the same spurious `Command output was lost: temp filesystem full (0MB free)` error when disk space is plentiful. The `CLAUDE_CODE_TMPDIR` workaround does not resolve it. This is a systemic bug in the temp filesystem monitoring layer that destroys trust in Bash tool output integrity on macOS.

**2. Windows path separator bugs are pervasive.**
Issues and PRs reveal that backslash-containing paths (`CLAUDE_PLUGIN_ROOT`, `C:\Users\...`) silently break bash scripts, hooks, and workflows. PRs #68694, #68699, #68700, and #68701 all address this from different angles. The fundamental problem: plugin authors write bash assuming Unix paths; Windows users get silent failures.

**3. Silent failures everywhere.**
Whether it's MCP installs hanging (#67865), config "disable cleanup" silently becoming an error (#68713), AskUserQuestion panels covering context (#62493), or CLI workflows crashing due to `set -u` on macOS bash 3.x (#68702) — the common thread is **no error, no feedback, no recovery path**. Developers are left diagnosing issues in the dark.

**4. Search self-corruption (#62016) erodes trust.**
When Claude corrupts its own `rg` output and then confidently acts on it, the debugging surface expands dramatically. Users must now verify every search result — which defeats the purpose of having an AI assistant do the searching.

**5. Workflow/agent state fragility.**
#65796's auto-compaction restart bug means long multi-agent runs are not resumable in a correct way. For teams building on Claude Code's workflow primitives, this is a blocker; completed work is silently re-executed, wasting tokens and wall-clock time.
