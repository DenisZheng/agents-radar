### Key Architectural Divergences

- **Session model**: Claude Code and Codex use JSONL-based session transcripts; Qwen Code exposes this via HTTP endpoints; OpenCode uses a SQLite-backed session DB that struggles at scale (#16270).

- **Multi-model**: OpenCode is the most provider-agnostic. Claude Code and Codex are tightly coupled to their respective model families. Qwen Code is investing in self-hosted LLM compatibility as a differentiator.
- **Release philosophy**: Claude Code and Qwen Code ship fast (patches/nightlies). Codex uses an alpha track for its Rust rewrite. Copilot CLI and Gemini CLI appear to be on slower, more cautious release cycles.

## 6. Trend Signals

### For Technical Decision-Makers

1. **MCP is the new plugin system, but it's not ready for enterprise.** Every tool has MCP reliability issues — session persistence, OAuth fan-out, proprietary serialization, missing permission controls. Organizations adopting MCP should budget for custom middleware or wait for governance features to mature. *Reference: Copilot #3028, #3706; Codex #26234; Gemini #27558.*

2. **Agent reliability is the next competitive frontier.** The honeymoon period of "the agent can code" is over. Users now demand *trustworthy* agents — no silent failures, no editing from memory, no false success reports. Tools that invest in observability (thinking display, undo reliability, session integrity) will win professional adoption. *Reference: Claude Code #49268, #64171; Gemini #22323; OpenCode #4704.*

3. **Windows is the neglected platform.** Across Codex, OpenCode, Copilot CLI, Kimi, and QSL, Windows users face crashes, sandbox failures, renderer freezes, and startup delays. Any team with a significant Windows/WSL user base should weight this heavily in tool selection. Linux/macOS-first development remains the norm.

4. **The daemon/remote-client architecture is emerging as a first-class pattern.** Qwen Code's Mode B, Codex's global instructions contributor API, and OpenCode's server API refactor all point to a future where the CLI is just one client head alongside IDE extensions, web UIs, and SDK consumers. Tools without a daemon story may find themselves limited to terminal-only use cases.

5. **Cost transparency is becoming a gating factor for adoption.** With Claude Code burning 2,000 GitHub Actions minutes in a single session (#65944) and Codex users watching quota drain passively (#26600), the lack of in-session budgeting controls is a real risk. Expect usage dashboards and hard spend limits to become table stakes.

6. **Declarative agent definitions are the next unlock.** Qwen Code (#4821), OpenCode (#29059), and Pi (spirit prompt metadata #5459) all point toward a future where agents are defined in Markdown/YAML rather than hardcoded in TypeScript. This dramatically lowers the barrier to custom agent creation and will likely become a key differentiator in 2026 H2.

## 3. Hot Issues

### 🔴 Critical / High Engagement

1. **[#49268](https://github.com/anthropics/claude-code/issues/49268) — Thinking summaries missing on Opus 4.7 (43 comments, 👍70)**
   The harness doesn't set `display: "summarized"` for Opus 4.7, so extended thinking summaries never render. This is the highest-engagement bug in the repo right now and has become a canonical reference for the thinking-display regression.

2. **[#63358](https://github.com/anthropics/claude-code/issues/63358) — Opus 4.8 returns empty thinking blocks (9 comments, 👍10)**
   Direct regression from #49268. Opus 4.8 returns thinking blocks with an empty `thinking` field, so the UI has nothing to render. Confirms the issue spans multiple model generations.

3. **[#64171](https://github.com/anthropics/claude-code/issues/64171) — Agent edits from memory, silent Edit failures shipped broken code to prod (7 comments)**
   A paying user reports a noticeable reliability regression: the agent is editing from memory rather than reading files, and silent Edit failures resulted in broken code reaching production. This strikes at the core trust proposition of agentic coding.

4. **[#62016](https://github.com/anthropics/claude-code/issues/62016) — Claude passes `rg -rn`, silently corrupts search output (2 comments, 👍8)**
   Claude's grep muscle memory hits `rg -rn`, but in ripgrep `-r` means `--replace`, so every match is silently rewritten to `n` with exit 0. Claude then reads its own corrupted output and misattributes results. A subtle but dangerous tool-use bug.

5. **[#63375](https://github.com/anthropics/claude-code/issues/63375) — Slash command during in-flight `advisor()` call permanently 400s session (6 comments)**
   Running `/usage` (or any local slash command) while an `advisor()` server-tool call is in flight corrupts the session JSONL, making the session permanently unrecoverable. A session-killing edge case.

6. **[#65938](https://github.com/anthropics/claude-code/issues/65938) — `advisor_tool_result` orphaned when `/goal` Stop-hook injects mid-roundtrip → permanent API 400 (2 comments, closed)**
   Companion to #63375. A `/goal` Stop-hook activation notice injected during an advisor roundtrip orphans the `advisor_tool_result` block, causing a permanent 400. Now closed.

7. **[#65867](https://github.com/anthropics/claude-code/issues/65867) — False-positive Usage Policy violation kills sessions during routine bug fixing (6 comments)**
   Sessions doing ordinary bug fixing on the user's own CRUD API are being killed mid-task with a Usage Policy violation error. Duplicate of an earlier report, suggesting this is a recurring filter issue.

8. **[#22685](https://github.com/anthropics/claude-code/issues/22685) — Claude Desktop App stuck in login loop with 'Invalid authorization' error (26 comments, 👍21)**
   Long-running auth issue. The Desktop app on macOS is completely unusable for affected users — every launch produces `Invalid authorization` errors and magic link login fails repeatedly.

9. **[#62706](https://github.com/anthropics/claude-code/issues/62706) — GrowthBook flag `tengu_pewter_brook` enables mouse reporting, breaks copy/paste in SSH terminals (3 comments)**
   An A/B test flag enables mouse reporting (`ESC[?1000h`) after login, which breaks copy/paste in SSH terminals (confirmed on MobaXterm). Affects WSL2/Docker users.

10. **[#65944](https://github.com/anthropics/claude-code/issues/65944) — Claude Code exhausted GitHub Actions monthly allotment (2,000 min) in a single session (1 comment)**
    A single Claude Code session burned through the entire GitHub Actions free tier. Highlights the need for better resource budgeting/limits for agentic CI workloads.
